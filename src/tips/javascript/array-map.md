# Array map()

The <code>map()</code> method is used to create a copy of an array and transforming the results. The new array is populated with the results of calling a provided function on every element in the original array. It is ideal for tasks like formatting, calculations, or extracting properties from objects.

In React, this is the method used to render lists of items (eseentially transforming data into components).

## Common use cases

- Converting a list of GBP values to USD
- Formatting an array of prices to add the currency symbol to each price
- Calculations applied to each element of an array e.g. return 75% of each number
- Extracting and transforming specific properties from an object
- Abbreviating strings such as 'Monday' to 'Mon'
